# Office Structure Linux Project

This project demonstrates basic Linux file and folder management using commands.

## Structure
- accounts (salary, bills)
- tech (dev, support)
- logs

## Operations Performed
- mkdir (folder creation)
- touch (file creation)
- echo (write data)
- cat (read data)
- cp (copy files)
- mv (rename/move files)

## Goal
To practice real-world Linux file handling operations.
